# Legacy plugin sources

`v0.4/` holds the Session, Person and Person2 plugins of AIBody 0.3/0.4 (protocol v1, character
slots `person1`/`person2`). They were replaced in 0.5.0 by the Client and Companion plugins in
`src/` and are kept for reference only: they are not built, checked or packaged, and the paths
inside them (e.g. `../Shared`) no longer resolve.

For a buildable tree of the old version, check out the tag `v0.4.0-session`
(`git checkout v0.4.0-session`).
